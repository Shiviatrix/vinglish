Compiler architecture

The compiler is organized in stages so that syntax, semantics, and code generation remain independent and observable.

source → lexer → parser → type inference → HIR → MIR → SSA → backend → executable

  • Lexer: tokenizes source text and recognizes the language keywords.
  • Parser: builds the AST and enforces syntax.
  • Type inference: resolves value types and ownership constraints.
  • HIR/MIR/SSA: lower the program into a compiler-friendly representation for optimization and analysis.
  • Backend: emits C or LLVM output for the runtime environment.
