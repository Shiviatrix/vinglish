The public stdlib is organized by responsibility, keeping utility APIs easy to discover and runtime helpers separate from user-facing modules.

  • std.io — basic input and output
  • std.time — timestamps and runtime timing helpers
  • std.random — random generation and value ranges
  • std.collections.list — dynamic list container
  • std.file and std.runtime — file and low-level runtime operations
