Vinglish Compiler Project

Vinglish

A systems programming language implementing keyword-based syntax and MIR-level ownership validation.
[ Home ] | [ Language Guide ] | [ Architecture ] | [ Standard Library ]

Features
  • Syntax: Replaces common symbolic operators with alphanumeric keywords.
  • Memory Safety: Validates object lifetimes via a Mid-level Intermediate Representation (MIR) ownership graph.
  • Code Generation: Emits C source code or LLVM IR.

Compilation Instructions (Requires Rust & C Compiler)

cargo install --path crates/vinglish
vng run hello.ving
