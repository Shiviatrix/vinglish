Vinglish

Readable systems programming

Vinglish is a systems programming language with English-like keywords, ownership-aware analysis, and a compiler pipeline that lowers source through lexing, parsing, type inference, HIR, MIR, SSA, and final C or LLVM code generation.

Docs hub Language guide Architecture Standard library GitHub

Install

Requires a Rust toolchain and a C toolchain. Install the compiler from the workspace and verify the CLI works.

cargo install --path crates/vinglish
vng --help

Quick start

Compile and run a basic program using the public example set.

vng check examples/basics/hello.ving
vng build examples/basics/hello.ving --output hello
./hello

Package system

The project includes a manifest and lockfile flow for reproducible builds, semver-aware dependencies, and registry metadata.

vng pkg init
vng pkg add core
