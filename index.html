Vinglish Compiler Project

Vinglish

A systems programming language focused on readability and memory safety.
[ Home ] | [ Language Guide ] | [ Architecture ] | [ Standard Library ]

Features
  • Syntax: Uses explicit keywords over cryptic symbols to improve code readability.
  • Memory Safety: Enforces strict lifetimes using an ownership graph at the MIR level.
  • Code Generation: Compiles directly to C source code or LLVM IR.

Quick Start (Requires Rust & C Compiler)

cargo install --path crates/vinglish
vng run hello.ving
