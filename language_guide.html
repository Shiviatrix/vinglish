Vinglish keeps the syntax readable without sacrificing systems-language behavior.

use std.io

function main()
returns number
begin
    print("Hello from Vinglish!")
    return 0
end

Core ideas

  • English-like keywords make control flow and declarations readable.
  • Type inference keeps the language ergonomic while preserving explicit contracts.
  • Ownership and borrowing are checked as part of the compiler pipeline.
  • Structs and type declarations remain explicit for large systems projects.
